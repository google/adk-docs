# Model Context Protocol (MCP) tools

Model Context Protocol (MCP) tools let your agents connect to outside databases, files, and services using an open standard. You can use them to give your agent access to existing tools, or turn your agent into a service that other apps can call. Explore the guides below to learn how to set up, customize, and deploy MCP tools in ADK.

## Topics

- **[Core and direct integration](./mcp-tools.md)**: Connect your agent to external MCP tools and fetch data with `McpToolset`.
- **[Advanced configuration](./mcp-tools-advanced.md)**: Pass user login tokens, manage sessions, and show rich UI components.
- **[Production deployment](./mcp-deployment.md)**: Package and run your MCP agents safely on Cloud Run or GKE.
- **[Agent as MCP server](./agent-as-mcp-server.md)**: Share your agent so outside programs like Claude Desktop or IDEs can use it.
- **[Sub-agent delegation](./agent-managed-mcp.md)**: Give tools to smaller helper agents to keep your main agent fast and accurate.
