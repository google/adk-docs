    Class BaseComputerAbstract

    Defines an interface for computer environments.

    This abstract base class defines the standard interface for controlling computer environments, including web browsers and other interactive systems. Coordinates passed to the action methods are absolute pixel values, scaled to the width and height returned by screenSize.

    The optional methods (doubleClick, tripleClick, middleClick, rightClick, mouseDown, mouseUp, keyDown and keyUp) are exposed to the model only when a subclass implements them.

    The Gemini 3.x actions click, move, type, scroll, take_screenshot, press_key and hotkey are always exposed. Each one calls the subclass method of the same name (click, move, type, scroll, takeScreenshot, pressKey, hotkey) when it is defined, and otherwise calls the matching predefined method.

    typeText

    • typeText(text: string, pressEnter?: boolean): Promise<ComputerState>

      Types text into the currently focused element.

      By default, this calls keyCombination once per character in text (and once for "Enter" when pressEnter is true). Because keyCombination is designed for key names and typically captures a new screenshot on every call, this fallback costs one round trip and screenshot per character, and relies on the backend accepting single characters in keyCombination. Subclasses should override this method to use native bulk text input.

      Parameters

      • text: string

        The text to type.

      • pressEnter: boolean = false

        Whether to press ENTER after typing.

      Returns Promise<ComputerState>

      The current state after typing.
