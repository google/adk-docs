RetryConfig

data class RetryConfig @JvmOverloads constructor(val maxRetries: Int = 3, val initialDelay: Duration = Duration.ofSeconds(1), val multiplier: Double = 2.0, val maxDelay: Duration = Duration.ofSeconds(10))

How BigQueryAgentAnalyticsPlugin retries a batch of rows that BigQuery failed to write.

Each wait is the current delay times a random factor between 1 and 2, capped at maxDelay. A retry after an unclear failure such as DEADLINE_EXCEEDED can write rows more than once, with the same event_id; a timed-out append is not retried, since the client may still write it.
