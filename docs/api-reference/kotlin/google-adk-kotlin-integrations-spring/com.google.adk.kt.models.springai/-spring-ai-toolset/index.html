SpringAiToolset

class SpringAiToolset(toolCallbackProvider: ToolCallbackProvider) : Toolset

Exposes every Spring AI tool from a ToolCallbackProvider as an ADK Toolset, so a dependency-injected provider (for example a Spring bean) contributes its tools to an ADK agent. Each callback is wrapped with SpringAiTool, and the provider is queried per request so tools it adds later are picked up.

Parameters

toolCallbackProvider

The Spring AI provider whose tools to expose.
