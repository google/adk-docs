Settings of a live run, held in RunConfig.live. They belong to the experimental live API, the only code that reads them, and may change without notice.

Properties from responseModalities to contextWindowCompression configure the live connection, set once when it opens and not changed per turn; saveLiveBlob instead tells ADK to record the conversation's audio and never reaches the connection.

val responseModalities: List<Modality>

The modalities the model may return. Empty leaves it unset, and the SDK then asks for audio on a live connection, as unset does in ADK Python. A value set here is sent as is, as in ADK Python, so a modality the model cannot answer in fails the connection.

val saveLiveBlob: Boolean

Whether to save the live input and output audio as artifacts, each referenced from an event the run emits. ADK never deletes these recordings, not even with the session, so prefer an artifact service backed by durable storage over an in-memory one for anything but short sessions.
