AuthCredential

@ExperimentalAuthApi
sealed interface AuthCredential

A credential that a tool uses to call a service: an ApiKey, an Http credential, an OAuth2 or OpenID Connect credential, or a ServiceAccount.

Secret fields are Secrets, so a credential's toString() prints them as <redacted>. OAuth2 also redacts its state, nonce, authUri and redirectUri, which are plain strings.
