SignInRequest

@ExperimentalAuthApi
class SignInRequest

A request from ADK for a credential one of the agent's tools needs, as Event.signInRequests finds it. Send the user to authUri when there is one, then answer with reply.

fun reply(credential: AuthCredential): Content

Returns the message that answers this request with credential, the one the user signed in for. An OAuth2 credential's tokens, code, expiry and any redirect URI fill in the request's own credential. Answer all pending requests in one message by combining their parts, since a resumable app can end the agent after the first answer.
