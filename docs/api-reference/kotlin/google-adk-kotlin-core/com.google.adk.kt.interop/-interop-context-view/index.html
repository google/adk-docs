InteropContextView

class InteropContextView

Java-friendly view of a Context: each method calls the suspend method of the same name and returns a CompletableFuture of its result, so Java callers never pass a Continuation. Each call runs in the caller's OpenTelemetry context, on the calling thread until it first suspends (so runNode children get their run IDs in call order) and then on Dispatchers.IO, as PublisherRunner runs agents. Each call is canceled with its future and with the Job given to of, if any, or otherwise when the node run that owns the context, if any, ends, so await each call before the node finishes.

@JvmOverloads
fun runNode(node: Node, nodeInput: Any? = null, config: RunNodeConfig = RunNodeConfig()): CompletableFuture<Any?>

Calls Context.runNode with the options in config; the future completes with the child's output, or null when it has none. Catch only failures you handle, such as DynamicNodeFailedException: when node pauses for input, the future fails with an internal Throwable that must end the calling node's run, so that the calling node waits too. node starts when this is called, before the calling node's published events are stored, so pass any data node needs as nodeInput or write that data to state in an earlier node.
