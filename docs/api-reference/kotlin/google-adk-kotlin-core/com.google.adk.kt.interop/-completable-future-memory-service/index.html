CompletableFutureMemoryService

class CompletableFutureMemoryService : AutoCloseable

Java-friendly wrapper around a MemoryService that it owns. Each method calls the suspend method of the same name and returns a CompletableFuture of its result, so Java callers never pass a Continuation. Canceling a future cancels its call, and close cancels every call in flight, then closes the service if it is AutoCloseable.
