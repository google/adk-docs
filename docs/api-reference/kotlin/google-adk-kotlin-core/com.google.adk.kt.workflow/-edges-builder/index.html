EdgesBuilder

@ExperimentalWorkflowApi
class EdgesBuilder

The receiver that collects the edges declared in an edges or workflow block. A node is identified by its instance, so create each node once and reuse it. To add a tool as a step, convert it once with asNode and reuse that node.

nodes

fun nodes(vararg nodes: Node): NodeGroup

Groups nodes without connecting them, as in a then nodes(b, c) for an infix fan-out or nodes(b, c).joinTo(join) for a join. Prefer this over listOf(b, c) for fan-outs and joins because listOf infers the nodes' closest common supertype. For some built-in nodes of different types, such as a Workflow and a JoinNode, that supertype is the framework-internal BaseNode, so the call fails to compile.
