EdgeChain

@ExperimentalWorkflowApi
class EdgeChain

A chain of edges for Java callers, positioned at a node. EdgesBuilder.from starts a chain, and each call adds the same edges as the edges DSL function of the same name and continues from its target.

@CanIgnoreReturnValue
fun chain(first: Node, second: Node, vararg rest: Node): EdgeChain

Connects the current node to first, second, and each node in rest in order, adding an edge from each node to the next and continuing from the last node. This adds the same edges as EdgesBuilder.chain would when starting from the current node: g.fromStart().chain(a, b) is the Java equivalent of chain(Start, a, b).
