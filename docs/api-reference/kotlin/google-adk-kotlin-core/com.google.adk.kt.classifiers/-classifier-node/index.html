ClassifierNode

@ExperimentalClassifierApi
@ExperimentalWorkflowApi
class ClassifierNode @JvmOverloads constructor(name: String, val classifier: Classifier, val question: Question, threshold: Double? = null, val answerKey: String? = null, description: String = "", rerunOnResume: Boolean = false, waitForOutput: Boolean = false, config: NodeConfig = NodeConfig(), inputSchema: Schema? = null, outputSchema: Schema? = null, stateSchema: Schema? = null) : BaseNode

Routes a workflow by asking a classifier one question about the node's input and emitting the answer as the route: the chosen label of a Choice, or true or false for a Binary, decided by threshold. The output is the unchanged input, or the underlying value unwrapped from a ClassifierInput, so the routed-to node receives what the classifier saw.

When the node has routed outgoing edges, graph validation checks that every route is a possible answer and that every possible answer has an edge, unless a default or unconditional edge catches the rest.

Parameters

threshold

For a Binary, the probability in [0, 1] at or above which the route is true, or null for 0.5. Setting it for a Choice is an error.

Throws

IllegalArgumentException

if name is empty or contains '/', '@', or '.'.

WorkflowConfigurationException

if question is a Score or uses Route.DEFAULT_ROUTE_SENTINEL, or if threshold is set on a Choice or lies outside [0, 1].
