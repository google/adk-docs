StreamableHttp

data class StreamableHttp(val url: String, val headers: Map<String, String> = emptyMap(), val connectTimeout: Duration = 5.seconds, val requestTimeout: Duration = 5.minutes, val allowInsecureHttp: Boolean = false) : McpTransportConfig

Streamable HTTP settings supported by both JVM and Android MCP clients.

HTTPS is allowed by default. An http endpoint requires allowInsecureHttp to be explicitly enabled on every platform. Android 9 / API 28 and newer normally block cleartext traffic as well, so the application must configure networkSecurityConfig or usesCleartextTraffic itself. A library cannot override that operating-system policy.
